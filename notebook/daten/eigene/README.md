# Eigene Classic-DICOM-Echos

Hier eigene Exporte ablegen. Im Notebook Schritt 1 auf eine Magnitudendatei der gewünschten Schichtebene ändern und in Schritt 8b `datenordner = "daten/eigene"` setzen. Ab Schritt 1 erneut ausführen; Aufnahme und Echo-Zuordnung prüfen.

Mehrere Schichten im Export sind erlaubt: Die Referenzdatei beschränkt die Auswertung auf genau eine geometrisch übereinstimmende Ebene. Dateiendungen sind nicht erforderlich. Für B₀ werden zwei direkte Phasenbilder mit zugehörigen Magnituden und dokumentierter Phasenskalierung benötigt.
